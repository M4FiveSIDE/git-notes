# Конспект по Git и GitHub

Краткая шпаргалка по базовым командам командной строки, работе с локальными репозиториями и синхронизации с GitHub.

## 1. Базовые команды командной строки (CLI)
* `pwd` — показать текущий путь к директории.
* `ls` / `ls -a` — показать список файлов (включая скрытые).
* `cd <папка>` — перейти в директорию (`cd ..` — на уровень выше, `cd ~` — в домашнюю папку).
* `mkdir <имя>` — создать новую папку (`mkdir -p` — создать вложенную структуру папок).
* `touch <файл>` — создать пустой файл.
* `cat <файл>` — вывести содержимое текстового файла в консоль.
* `rm <файл>` / `rm -r <папка>` — безвозвратно удалить файл или папку.

## 2. Настройка и инициализация Git
* `git config --global user.name "Ваше Имя"` — задать имя автора коммитов.
* `git config --global user.email "email@example.com"` — задать почту автора коммитов.
* `git init` — превратить текущую папку в локальный Git-репозиторий (создаётся скрытая папка `.git`).

## 3. Работа с изменениями и коммитами
1. `git status` — проверить текущее состояние файлов (*untracked*, *staged*, *modified*).
2. `git add <файл>` (или `git add .`) — добавить файлы в индекс для подготовки к коммиту.
3. `git commit -m "Описание изменений"` — зафиксировать изменения в истории репозитория.
4. `git log` — просмотреть историю всех коммитов.

## 4. Работа с удалённым репозиторием (GitHub)
* `ssh-keygen -t ed25519 -C "email@example.com"` — сгенерировать пару SSH-ключей для безопасного подключения.
* `git remote add origin <SSH-ссылка>` — привязать локальный репозиторий к удалённому на GitHub.
* `git remote -v` — проверить привязку удалённого репозитория.
* `git push -u origin main` — отправить локальные коммиты на GitHub (в дальнейшем достаточно `git push`).
* `git clone <SSH-ссылка>` — скопировать удалённый репозиторий на компьютер.
